## Cấu trúc thư mục dự án

| Thư mục | Nội dung |
| :--- | :--- |
| `docs` | Tài liệu bàn giao |
| `data` | Bảng tính bán vé vào cổng |
| `logs` | Log truy cập website|

## Lệnh liệt kê dự án
